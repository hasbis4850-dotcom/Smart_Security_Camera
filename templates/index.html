🔒 Privacy Policy & Data Security

1. Local Data Storage: All video feeds, captured alert images, and vehicle license plate logs are stored strictly locally on this device inside the AI_Security_Alerts directory. No footage is uploaded to external cloud servers.

2. Automated AI Processing: Real-time object detection (YOLOv8) and optical character recognition (EasyOCR) run locally on the host machine to ensure maximum speed and privacy.

3. Authorized Access Only: Access to this localhost dashboard and its recorded evidence is restricted to authorized system administrators only.

4. Ethical Surveillance: This system is designed solely for personal property security, vehicle monitoring, and academic research purposes.
